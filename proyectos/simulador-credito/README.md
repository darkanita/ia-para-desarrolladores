# simulador-credito

Punto de partida para construir, con un asistente de IA, un simulador de crédito de consumo.

- `REQUISITOS.md`: la pregunta de negocio y lo que debe hacer la aplicación.
- `AGENTS.md`: las reglas del equipo, que leen Copilot y Claude Code (este último a través de `CLAUDE.md`).

Todavía no hay código: lo escribe el asistente.
