# Simulador de crédito · construido con GitHub Copilot

Esta carpeta se abre sola en VS Code y se le pide a **Copilot Chat** (agente Agent) que construya la aplicación.

Lo que Copilot necesita ya está aquí:

- `REQUISITOS.md`: la pregunta de negocio y lo que debe hacer la aplicación.
- `AGENTS.md`: las reglas del equipo. Copilot lo lee automáticamente.

El resto de archivos (`simulador/`, `app.py`, `tests/`) los escribe Copilot en clase y se guardan tal como los dejó.
