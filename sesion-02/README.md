# Sesión 2 — Explorar: las herramientas en sus máquinas y el ciclo AI SDLC

**Módulo 2 · 2 horas**

## Objetivo
Ver a los agentes construir una aplicación a partir de requisitos, entender el ciclo de desarrollo con agentes (AI SDLC) que seguiremos el resto del curso, y conocer la primera pieza del agente del equipo: la skill `/intencion`.

## Agenda

| Tiempo | Bloque | Material |
|---|---|---|
| 0:00 – 0:10 | Repaso y lo que pidió el grupo | Presentación |
| 0:10 – 0:20 | Demo A: alucinación y datos sensibles | Presentación |
| 0:20 – 0:55 | Demo B: Copilot y Claude Code construyen el simulador de crédito desde requisitos, mientras vemos qué es el SDLC y el ciclo AI SDLC | `sesion-01/resultados/` |
| 0:55 – 1:10 | Demo: el repositorio del equipo y la skill `/intencion` | `proyectos/plantilla-equipo` |

| 1:50 – 2:00 | Tarea y cierre | Presentación |

## Antes de la clase
Llegue con su máquina lista: repositorio del curso descargado, entorno de Python activo y Claude Code o Copilot con sesión iniciada. Revise los [requisitos para la parte práctica](../preparacion/REQUISITOS_PRACTICA.md).
