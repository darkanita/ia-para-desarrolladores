# Retos sugeridos · Banco Orquídea (ficticio)

Ideas para el reto del equipo. Todas usan datos sintéticos y las reglas de `banco.yaml`. Pueden proponer otro del trabajo diario si cumple lo mismo.

| Reto | Tipo de entregable | Qué lo hace interesante |
|---|---|---|
| Validador de transferencias | Componente / API | Límite diario, GMF, cuentas bloqueadas, enmascaramiento |
| Modernizar la conciliación heredada (`retos/conciliacion-legacy/`) | Modernización de código heredado | Código de 2017 sin pruebas: entenderlo, probarlo y refactorizarlo |
| Alertas de transacciones inusuales | Proceso ETL + reglas | Reglas de monto, frecuencia y horario sobre datos sintéticos |
| Generador de extractos | Componente + reporte | Saldos, movimientos y formato; datos restringidos enmascarados |
| API de consulta de productos de un cliente | API (FastAPI) | Contratos, validación y datos sintéticos de clientes |
| Calculadora de capacidad de pago | Componente | Endeudamiento, otras deudas, recomendación de monto y plazo |
| Pruebas para un módulo existente | Suite de pruebas | Cobertura del dominio, casos borde y datos sintéticos |

El simulador de crédito de la sesión 1 queda como **ejemplo resuelto**: no lo elijan como reto.
