# Material de referencia por sesión

El curso usa como referencia dos rutas oficiales y gratuitas:

- **Microsoft Learn**, módulos sobre GitHub Copilot (en español: cambie `en-us` por `es-es` en la dirección).
- **Anthropic Academy**, en especial **Claude Code 101**, que va de la instalación a la personalización avanzada (CLAUDE.md, subagentes, skills, MCP y hooks).

Se recomiendan como lectura de apoyo antes o después de cada sesión. No reemplazan los laboratorios del curso, que usan casos del sector financiero.

| Sesión | Tema del curso | Microsoft Learn (GitHub Copilot) | Anthropic Academy (Claude Code) |
|---|---|---|---|
| S1 | Cómo funciona un LLM; cómo trabaja un agente; qué modelo usar | [Introduction to GitHub Copilot](https://learn.microsoft.com/en-us/training/modules/introduction-to-github-copilot/1-introduction) · *Responsible AI with GitHub Copilot* | [Claude Code 101](https://anthropic.skilljar.com/claude-code-101): *What is Claude Code?*, *How Claude Code works* · *AI Capabilities and Limitations* |
| S2 | Copilot Chat, Copilot CLI y Claude Code | [Get started with GitHub Copilot](https://learn.microsoft.com/en-us/training/modules/get-started-github-copilot/1-introduction) · [GitHub Copilot Across Environments](https://learn.microsoft.com/en-gb/training/modules/github-copilot-across-environments/1-introduction) | Claude Code 101: *Installing Claude Code*, *Your first prompt*, *Daily workflows*, *Explore → plan → code → commit* |
| S3 | Prompt y context engineering; instrucciones del equipo | [Introduction to prompt engineering with GitHub Copilot](https://learn.microsoft.com/en-us/training/modules/introduction-prompt-engineering-with-github-copilot/1-introduction) | Claude Code 101: *Context management*, *Customizing Claude Code*, *The CLAUDE.md file* |
| S4 | De historia de usuario a caso de uso con la plantilla | *Using GitHub Copilot with Python* · *Building applications with GitHub Copilot agent mode* | Claude Code 101: *Skills* · *Introduction to Agent Skills* |
| S5 | Depuración y code review con agentes | *Leveling up code reviews and pull requests with GitHub Copilot* | Claude Code 101: *Code review*, *Subagents* · *Introduction to Subagents* |
| S6 | Pruebas y refactorización | *Develop unit tests using GitHub Copilot tools* | Claude Code 101: *Hooks* |
| S7 | Seguridad | *Responsible AI with GitHub Copilot* · *Management and customization considerations with GitHub Copilot* (exclusión de contenido) | *AI Capabilities and Limitations* · *Claude Code in Action* (buenas prácticas) |
| S8 | Gobierno y empaquetado del cerebro del equipo | [Generate documentation using GitHub Copilot tools](https://learn.microsoft.com/en-us/training/modules/generate-documentation-using-github-copilot-tools/1-introduction) · *Introduction to MCP Server* | Claude Code 101: *MCP* · *Introduction to Model Context Protocol* |
| S9–S10 | Reto aplicado | Ruta de preparación de la certificación **GH-300 (GitHub Copilot)** | *Claude Code in Action* |

Para elegir modelo (S1), consulte las páginas oficiales, que cambian cada pocos meses:

- [Modelos disponibles en GitHub Copilot](https://docs.github.com/en/copilot/reference/ai-models/supported-models)
- [Configuración de modelos en Claude Code](https://code.claude.com/docs/en/model-config) (`/model`, `/effort`, alias como `opusplan`)
- [Cómo elegir un modelo Claude](https://platform.claude.com/docs/en/about-claude/models/choosing-a-model)

Los títulos en cursiva son módulos o cursos con ese nombre en cada plataforma; búsquelos por título en [Microsoft Learn](https://learn.microsoft.com/training/) o en [Anthropic Academy](https://anthropic.skilljar.com/).

Las dos plataformas ofrecen insignias o certificados al completar los cursos. No son requisito del curso.
